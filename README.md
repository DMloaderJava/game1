# АРХИТЕКТОР ПАРАДОКСОВ

**Концепт сюрреалистической 3D-игры от первого лица + играбельный прототип.**

Ты — Разломщик: существо, которое может на 8 секунд отменить законы физики в радиусе 18 метров.
Мир — живой организм размером с континент, который постоянно перестраивает сам себя и помнит всё, что ты сделал.

---

## Что лежит в репозитории

| Путь | Что это |
|---|---|
| **`index.html`** | Визуальная презентация концепта (открывать первой) |
| **`docs/CONCEPT.md`** | Полный концепт-документ: 4 биома, бестиарий, босс, прогрессия, сеты плей, тех-план |
| `docs/concept.html` | Тот же документ, отрендеренный в HTML (для чтения в браузере) |
| **`prototype/`** | Играбельный вертикальный срез на three.js — перемотка, скульптура, эхо, коллапсы, враги, два финала |
| `art/` | Концепт-арт (7 изображений) |
| `tools/render-doc.mjs` | Пересборка `docs/concept.html` из Markdown |

---

## Как запустить

Любой статический сервер из корня репозитория:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

- `http://localhost:8080/` — презентация концепта
- `http://localhost:8080/prototype/index.html` — прототип (нужен браузер с WebGL)

> Прототип — ES-модуль, поэтому его нельзя открывать через `file://`: нужен http-сервер.

## Управление в прототипе

| Клавиша | Действие |
|---|---|
| `WASD` + мышь | движение / обзор |
| `Space` | прыжок |
| `Shift` | рывок-разлом |
| `Q` (удерживать) | локальная перемотка пузыря 18 м |
| `E` | оставить эхо (призрак-платформа) |
| `ЛКМ` (удерживать) | лепить материю |
| `ПКМ` | уплотнить в нестабильную структуру |
| `Tab` | слой памяти (замедление + прошлое моста) |
| `1` / `2` у Ядра | стабилизировать / довести коллапс |

**Задача:** дойти до Ядра. На пути — пропасть, мост, который рухнул 4 секунды назад, три Шва, Мнемофаг, Реверс и 14 метров, которые придётся пересечь самому.
