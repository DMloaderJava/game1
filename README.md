# АРХИТЕКТОР ПАРАДОКСОВ

**Сюрреалистическая 3D-игра от первого лица: концепт-документ + полностью играбельная кампания в браузере.**

Ты — Разломщик: существо, которое может на 8 секунд отменить законы физики в радиусе 18 метров.
Мир — живой организм размером с континент, который постоянно перестраивает сам себя и помнит всё, что ты сделал.

---

## Что в репозитории

| Путь | Что это |
|---|---|
| **`index.html`** | Визуальная презентация концепта |
| **`prototype/index.html`** | **Игра**: 4 биома + финальный босс + два финала |
| `docs/CONCEPT.md` | Полный концепт-документ (≈76 КБ: биомы, бестиарий, босс, прогрессия, сеты плей, тех-план) |
| `docs/concept.html` | Тот же документ в HTML |
| `prototype/src/` | Исходники игры (ES-модули, three.js r160, ~3500 строк) |
| `art/` | Концепт-арт (7 изображений) |
| `tools/render-doc.mjs` | Пересборка `docs/concept.html` из Markdown |

## Как играть

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Открой `http://localhost:8080/prototype/index.html` (нужен браузер с WebGL; через `file://` модули не загрузятся).

### Что внутри кампании

| Зона | Закон биома | Что нужно сделать |
|---|---|---|
| **Лёгкие Хора** | дышащие платформы + мост, который рухнул 4 секунды назад | разрушить 3 узла |
| **Медный Позвоночник** | восходящие потоки и гравитационные колодцы, вертикаль 30 м | разрушить 3 узла |
| **Канцелярия Невозможных Этажей** | фазовые платформы: то есть, то нет | разрушить 3 узла |
| **Мембрана** | волны стирания: платформы исчезают на 5,6 с | разрушить 3 узла |
| **ХОР-НОЛЬ** | три фазы: эхо-копии → ревизия (босс откатывает тебя) → осыпающаяся арена | победить и выбрать финал |

Между зонами — экран **вплетения**: осколки тратятся на три ветки (Стазис / Потоп / Распад).
Финал — не кнопка в диалоге: подойди к ядру и нажми `1` (стабилизировать) или `2` (довести коллапс).

### Управление

| Клавиша | Действие |
|---|---|
| `WASD` + мышь | движение / обзор |
| `Space` | прыжок |
| `Shift` | рывок-разлом |
| `Q` (удерживать) | локальная перемотка пузыря 18 м |
| `E` | оставить эхо (призрак-платформа) |
| `ЛКМ` (удерживать) | лепить материю |
| `ПКМ` | уплотнить в нестабильную структуру |
| `Tab` | слой памяти (замедление) |
| `Esc` | пауза, настройки |

**Ядро цикла:** слепи структуру → уплотни в нестабильную → подорви рядом с узлом или врагом → откати мир, если стало плохо.
Лечение — только перемоткой собственного тела в прошлое. Аптечек нет.

### Как это проверялось

Игровая логика прогоняется в Node с заглушками DOM/WebGL (`prototype/src` — чистые ES-модули):
загрузка всех пяти зон, полный маршрут «узел → портал → прокачка → следующая зона», бой с боссом,
покупка апгрейдов, оба финала и 9000 кадров случайного ввода — без единого исключения.
